# Changelog

## [1.0.2] - 2026-08-11

### Added

- Added an in-game TNT Trails settings screen from Minecraft Options.
- Added configurable trail lifetime from 1 to 60 seconds.
- Added selectable gradient start and end colors.
- Added persistent client settings in `config/tnttrails.properties`.
- Added explosion location markers with configurable trail styling.

### Changed

- Updated trail rendering for Minecraft 26.2's gizmo pipeline.
- Added path-based color gradients with time-based fading.
- Added smoothed trails and a subtle depth-aware glow.
- Reduced explosion marker size to 0.7 blocks.
